# 三命通會 — Siku Quanshu edition

A complete twelve-juan Markdown export of the Chinese Wikisource transcription specifically labelled **三命通會 (四庫全書本)**. The repository name `Sanming-Tongshui` is retained as requested; the work is conventionally romanized *Sanming tonghui*.

The `source/` directory contains **exactly twelve UTF-8 Markdown files**, one per juan. The Siku editorial notice **提要**, published separately on Wikisource's work page, is included at the beginning of `source/juan-01.md`, so it is not omitted and no thirteenth text file is needed.

## What is preserved

The files contain the source text, not summaries or translations. All text inside each source page's `onlyinclude` / `poem` region is retained, including the inline notes, source section labels, closing volume labels and classification lines. The order of the source lines is preserved; leading indentation and excess blank lines are normalized. Standalone source anchors become Markdown headings. Wikisource's `SK notes` content is displayed with its text-export delimiters, `〈…〉`.

Rare-character placeholders are expanded using Wikisource's own `SKchar` mapping at export time. **57 distinct mappings** resolve to Unicode. **26 distinct image-only glyphs**, occurring **126 times**, are retained as inline SVG images with identifying alternative text. Their files are stored in `assets/glyphs/`, outside `source/`; they are glyph images, not font files. Keep the assets directory with the Markdown for offline rendering. The filenames, source URLs, checksums and Commons attribution records are in `SOURCE_MANIFEST.json`.

Wikisource navigation, site-interface text, HTML styling and copyright banners are not part of the book text and are excluded. Per-file YAML metadata and HTML region markers are added for provenance and mechanical validation.

## Verification and scope

All **13 textual source bodies** (the preface and twelve juan) were checked in three forms: revision-pinned wikitext, the saved Markdown, and MediaWiki-rendered HTML for the same revision. After removing whitespace and added Markdown heading markers, and treating each matching image ID as a glyph token, their character sequences match exactly. The saved source files also have SHA-256 checksums recorded in `SOURCE_MANIFEST.json`.

This establishes a complete, loss-checked export of the named **Wikisource transcription**. It is **not** a fresh transcription or an independent line-by-line collation against historical page scans. Existing transcription errors, uncertain readings and source conventions are retained rather than silently corrected. The edition label follows Wikisource's source identification.
